# 赛博领鸡蛋 · 看板

由原先的纯前端 Demo 演进而来，仍可单独打开。

默认是公开模式：不会模拟「领取成功」，也不会把演示数字加总成真实人民币收益。未加载扩展时，魔搭卡片显示「尚未读取 / 无每日签到」，其他卡片保留演示数据，但操作会走已核实的官方入口或标明「尚未接入真实领取」。

官方余额查询、个人领取记录和授权，必须用下面的本机地址打开，并安装配套扩展。扩展目前只匹配 `localhost` / `127.0.0.1`，公开测试站无法连接扩展，也不能自动领取。令牌只留本机。

本机且扩展已连接时，左侧有「授权自动领取 / 取消授权 / 立即执行一次 / 开启或关闭每日自动领取 / 最近一次结果」。授权会打开该平台官网，让你自己登录；回来点「我已在官网完成登录」后显示已授权。这些按钮不会走演示模式的模拟签到。公开页上它们是停用的。余额和有效期只展示官方读到的结果。

在仓库根目录启动：

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080/web/

URL 参数：

- `?demo=1` 开启演示模式：可模拟领取交互，页面会持续标明「模拟」，不会向任何平台发送请求。可与 `?fixture=modelscope` 并存。
- `?fresh=1` 持久清除本机保存的卡片状态和羊毛「已领 / 不感兴趣」标记（需要重置时再用；日常测试不要默认带上）。可与 `?demo=1` 同时使用，不会因此关闭演示模式。
- `?open=<cardId>` 直接打开某张卡片（例如 `modelscope`）
- `?guide=0|1` 关闭/开启新手引导
- `?fixture=modelscope` 用官方 OpenAPI 文档中的示例余额演示魔搭卡片，不发起真实请求。页面会标明「夹具演示」，余额不是你的真实账户。
- `?deal=<id>` 或 `?open=deal:<id>` 直接打开「薅羊毛」里的某条活动（例如 `siliconflow-ambassador`）

公开测试站日常请用 `https://saibo-lingjidan.surge.sh/?guide=0`。演示模式用 `?demo=1&guide=0`。

扩展的安装、令牌保存和真实余额读取，见仓库根目录 README。

「薅羊毛」数据从 `../deals/deals.json` 加载。加载器计算档期与核验是否过期；页面按频次、核验状态、档期等组合筛选，并把「已领 / 不感兴趣」标记保存在浏览器本地。无截止日期不再视为「进行中」。
